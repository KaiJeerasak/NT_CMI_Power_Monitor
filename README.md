# NT Chiang Mai Power Monitor

เว็บแดชบอร์ดติดตามสถานีไฟฟ้าสำรอง พัฒนาด้วย Next.js App Router, React และ TypeScript

## เริ่มใช้งานในเครื่อง

ต้องใช้ Node.js 20.9 ขึ้นไป และ pnpm

```bash
pnpm install
Copy-Item .env.example .env.local
pnpm dev
```

เปิด `http://localhost:3000` จากนั้นกำหนดค่าใน `.env.local` ตามหัวข้อด้านล่างและรีสตาร์ต Next.js เมื่อแก้ environment variables

## Environment variables

| ตัวแปร | ใช้สำหรับ |
| --- | --- |
| `NEXT_PUBLIC_LONGDO_MAP_KEY` | Longdo Map browser key ควรจำกัดโดเมนที่อนุญาตใน Longdo console |
| `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` | เชื่อมต่อ MariaDB เพื่ออ่านข้อมูลสถานี |
| `STATION_STALE_AFTER_SECONDS` | อายุข้อมูลสูงสุดก่อนแสดงสถานีเป็นออฟไลน์ (ค่าเริ่มต้น 600 วินาที) |

ห้าม commit `.env.local`, รหัสผ่าน, token หรือ key จริง ใช้ `.env.example` เป็นเพียงรายการชื่อตัวแปรและค่าตัวอย่างเท่านั้น

## ฟังก์ชันหลัก

- ภาพรวมสถานีบนแผนที่ พร้อมสถานะและรายการแจ้งเตือนล่าสุด
- API อ่านข้อมูลปัจจุบันจาก MariaDB โดยใช้ `site_cmi`; ประวัติอ่านจาก `site_log`
- กฎ Alarm แรงดัน AC ต่ำกว่า 150 V และสถานะอุปกรณ์ที่กำหนดรายสถานี
- ศูนย์แจ้งเตือนพร้อมการรับทราบเหตุ และข้อมูลเหตุไฟฟ้าขัดข้อง/แรงดัน DC
- ประวัติ กราฟแนวโน้ม และส่งออก CSV ตามช่วงเวลาที่เลือก
- ตั้งค่าระบบไฟฟ้า Battery Backup และเครื่องกำเนิดไฟฟ้ารายสถานี
- ปุ่มจำลองเหตุการณ์บนหน้าเว็บ ใช้แสดงผลเท่านั้น ไม่เขียนฐานข้อมูลหรือสั่งอุปกรณ์จริง

## ขอบเขตและข้อควรทราบ

การเชื่อมต่อ MariaDB เป็นแบบอ่านข้อมูลสถานี/ประวัติเท่านั้น การรับทราบและค่ากำหนดบางส่วนเก็บใน browser storage ยังไม่มีระบบบัญชีผู้ใช้หรือ audit log ฝั่ง server และยังไม่ได้เชื่อม Supabase/MQTT หรือส่งการแจ้งเตือนออกนอกเว็บ ต้องตรวจ schema, สิทธิ์ฐานข้อมูล, data mapping, RLS และแนวทางสำรองข้อมูลก่อนใช้งานจริง

ค่า `load_dc` และ `wifi` ยังคงแสดงเป็นค่าดิบจนกว่าจะยืนยันหน่วย ส่วนพิกัดสถานีควรตรวจสอบกับตำแหน่งจริงก่อนนำไปใช้ปฏิบัติงาน
